# ✦ Telegram Aesthetic Userbot & Purge Engine

Современный юзербот для Telegram на базе **Telethon**, генерирующий минималистичные графические дизайн-карточки (в швейцарском темном стиле / Dark Modern UI, без аляповатого нейрослопа) на каждое действие и команду.

## 🛠 Возможности

1. **Полная очистка своих сообщений (`.delall` / `.purge_me` / `.delme`)**:
   - Находит и безвозвратно удаляет **все сообщения пользователя когда-либо написанные** в выбранном диалоге.
   - Поддерживает:
     - Очистку текущего чата: `.delall`
     - Очистку любого другого чата или группы: `.delall @username` или `.delall -1001234567890`
   - Пакетное удаление пачками по 100 сообщений с встроенной защитой от `FloodWait` (Rate Limits) Telegram.
   - По завершении генерирует стильную карточку с метриками: количество удаленных сообщений, целевой диалог, затраченное время и скорость (сообщений в секунду).
2. **Диагностика системы (`.ping`)**:
   - Замеряет реальную сетевую задержку до серверов Telegram MTProto и время непрерывной работы (аптайм).
3. **Графическая справка (`.help`)**:
   - Выводит красивый структурированный список всех доступных команд.
4. **Дизайн-система карточек**:
   - Строгая темная палитра (#0A0C10, #10131A, #202632).
   - Точные шрифты, статус-бейджи (SUCCESS, ONLINE, TIMEOUT, ERROR), моноширинные числовые показатели.
   - Отправка напрямую из оперативной памяти (`io.BytesIO`) без создания временного мусора на диске.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Получение ключей Telegram API
1. Перейдите на официальный сайт [my.telegram.org](https://my.telegram.org) и авторизуйтесь по номеру телефона.
2. Откройте раздел **API development tools**.
3. Создайте приложение (название может быть любым, например `myuserbot`).
4. Скопируйте **`api_id`** (число) и **`api_hash`** (строка).

### 3. Настройка файла `.env`
Скопируйте пример конфигурации:
```bash
copy .env.example .env
```
Откройте файл `.env` и вставьте ваши данные:
```env
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef0123456789abcdef0123456789
SESSION_NAME=userbot_session
COMMAND_PREFIX=.
```

### 4. Запуск юзербота
```bash
python main.py
```
При первом запуске Telethon запросит в терминале:
1. Номер телефона вашего аккаунта (в международном формате, например `+7999...`).
2. Код подтверждения из Telegram.
3. Пароль двухфакторной аутентификации (2FA), если он включен.

После этого сессия сохранится в файл `userbot_session.session`, и последующие запуски будут проходить мгновенно и автоматически!

## 📋 Список команд в Telegram

| Команда | Описание |
| :--- | :--- |
| `.update` / `.upgrade` | **Беспроводное обновление (OTA)**: `git pull` с GitHub + автоперезапуск |
| `.restart` | **Перезапуск юзербота** через системную службу |
| `.plugins` / `.menu` | **Центр управления плагинами** (каталог с графической карточкой статусов) |
| `.animequiz` / `.guess` | **Аниме-викторина**: интерактивная игра «Угадай аниме по кадру» с таймером на 45 сек. |
| `.animequiz stop` / `.guess stop` | Принудительно остановить активный раунд викторины в текущем чате |
| `.online on` / `.online off` | **Вечный онлайн** (удержание статуса "В сети" 24/7) |
| `.autoname on` / `.autoname off` | **Время в никнейме** (поминутное обновление времени в имени) |
| `.autoname tz <+/-смещение>` | Изменить часовой пояс времени в имени (например `.autoname tz +3`) |
| `.plugin <name> on\|off` | Быстрое включение/отключение любого плагина |
| `.delall` | Удалить все свои сообщения когда-либо отправленные в текущем чате |
| `.delall @chat` | Удалить все свои сообщения в указанном чате / группе / канале |
| `.delall -100xxxx` | Удалить все свои сообщения по числовому ID чата |
| `.purge_me` | Синоним команды `.delall` |
| `.ping` | Проверить статус, аптайм, RAM и задержку до серверов Telegram MTProto |
| `.help` | Открыть визуальную карточку со справкой по всем командам |

## 🧩 Система плагинов и модулей

В юзербот встроена расширяемая модульная система с сохранением состояния при перезагрузках:
1. **Вечный онлайн (`always_online`)**:
   - Отправляет невидимый фоновый пинг `UpdateStatusRequest(offline=False)` каждые 25 секунд.
   - Аккаунт отображается в Telegram как «В сети» непрерывно 24/7.
2. **Время в никнейме (`time_name`)**:
   - Автоматически считывает ваше исходное имя при включении и бережно сохраняет его.
   - Каждую минуту ровно в 00 секунд обновляет имя профиля на `[Имя | ЧЧ:ММ]`.
   - При отключении (`.autoname off`) мгновенно возвращает исходное имя назад без потерь!

## 🌐 Круглосуточный запуск 24/7 на выделенном сервере (Linux / VPS)

Проект оптимизирован для непрерывной автономной работы 24/7:
- **Автореконнект**: Внешний цикл устойчивости с экспоненциальной задержкой автоматически восстанавливает соединение при сбоях сети или дата-центра.
- **Встроенные шрифты**: В `assets/fonts/` встроены шрифты Roboto и RobotoMono с полной поддержкой кириллицы — карточки генерируются с идеальной типографикой даже на минимальных headless Linux-серверах без X11.
- **Ротация логов**: Логи автоматически пишутся в `logs/userbot.log` с ротацией (до 5 файлов по 10 МБ), предотвращая переполнение диска.
- **Безопасное завершение**: Обработка сигналов `SIGTERM`/`SIGINT` предотвращает повреждение базы сессии SQLite при перезагрузке сервера.

### Вариант 1: Быстрая автоматическая установка (systemd)
Склонируйте проект на сервер и выполните:
```bash
chmod +x deploy.sh
./deploy.sh
```
Скрипт сам создаст виртуальное окружение, установит зависимости, настроит `.env`, запросит авторизацию в Telegram и зарегистрирует службу `systemd` с автоматическим перезапуском при перезагрузке сервера.

**Полезные команды управления службой:**
```bash
sudo systemctl status telegram-userbot   # Статус службы
sudo systemctl restart telegram-userbot  # Перезапуск бота
sudo systemctl stop telegram-userbot     # Остановка бота
sudo journalctl -u telegram-userbot -f   # Просмотр системных логов в реальном времени
tail -f logs/userbot.log                 # Просмотр файла логов
```

### Вариант 2: Запуск через Docker Compose
1. Настройте файл `.env`.
2. Запустите первоначальную авторизацию:
```bash
docker compose run --rm userbot python main.py
```
3. После создания сессии запустите фоновый контейнер с автоперезапуском:
```bash
docker compose up -d
docker compose logs -f
```
